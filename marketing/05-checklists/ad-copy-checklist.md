# Ad Copy Checklist

Run on every piece of ad or landing copy before it ships — new or edited,
paid or organic. Referenced from `sop-ad-copy-review.md`.

## Compliance (non-negotiable — `brand.md`)

- [ ] No implied guarantees, "safe," or specific-return claims
- [ ] No "tips," "recommendation," or "signal" language
- [ ] Educational/non-advisory framing is clear, not just present in fine
      print
- [ ] Any stat/number claim is currently verifiable — cut it if unsure

## Voice (`brand.md` + `copywriting-playbook.md`)

- [ ] Reads calm, not hyped — no manufactured urgency ("limited seats,"
      "don't miss out") unless factually true at the moment of publishing
- [ ] Plain language — no unexplained jargon for a beginner audience
- [ ] Matches the angle assigned to this persona in
      `copywriting-playbook.md`'s angle-to-persona map

## Message match

- [ ] The promise in the headline is visible on the actual landing
      destination within the first screen
- [ ] CTA language matches the site's actual CTA wording ("Book a Free
      Intro Session," not an invented variant that sets a different
      expectation)

## Mechanics

- [ ] Within character limits for the placement (Search headline ~30
      char, description ~90 char)
- [ ] No spelling/grammar errors — read it aloud once
- [ ] If this is a test variant, it's logged against the CRO experiment
      backlog (`landing-page-cro-playbook.md`) with a clear hypothesis

## Sign-off

- [ ] CMO lens has reviewed (`01-agent-architecture/raci.md`)
