# Monthly Workflow

The strategic layer — restructuring, budget-tier decisions, and the
questions that need a full month of data to answer honestly.

## The monthly block (~2–3 hours)

1. **Publish the monthly strategic report**
   (`07-reporting/monthly-report-template.md`), rolling up the four/five
   weekly reports into trend lines, not just a snapshot.
2. **Revisit the bidding-strategy stage gate**
   (`02-playbooks/google-ads-playbook.md`) — this is the right cadence to
   actually move stages (Manual CPC → Maximize Conversions → Target CPA),
   unlike the weekly cycle which only tunes within a stage.
3. **Revisit budget allocation.** If more than one channel is live, this is
   where the Performance Marketing Expert lens reallocates based on
   trailing CPQL by channel, not weekly noise.
4. **Account structure review.** Should any ad group be split (persona
   proving heterogeneous) or merged (too little volume to learn from
   separately)? This is a monthly-or-slower decision, never weekly.
5. **Run the quarterly competitor teardown if due**
   (`06-prompts/competitor-teardown.md`, `00-knowledge-base/competitors.md`)
   — check the last-run date before assuming it's due.
6. **Re-audit the site** against
   `00-knowledge-base/audit-findings.md` — mark closed items, add any newly
   discovered issues. A full audit doesn't need to be run from scratch
   monthly, but the findings file should never go stale for more than a
   quarter.
7. **Revisit the CRO experiment backlog priority order**
   (`landing-page-cro-playbook.md`) — re-rank based on what's shipped and
   what new evidence the month produced.
8. **Roadmap check-in with the founder.** Is the current `ROADMAP.md` phase
   on track to close? Does anything need re-scoping before requesting the
   next phase's approval?

## Output

A monthly report the founder can read in under 10 minutes and know: what
happened, what changed, what's being asked for next, and what's blocked.
